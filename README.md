## 🚀 Key Features

- **🚨 1-Tap Emergency SOS:** Prominent 1-tap SOS button triggering a 7-second countdown before dispatching emergency SMS alerts.
- **📍 Live GPS Location Sharing:** Includes real-time Google Maps links in emergency SMS notifications.
- **📷 Background Silent Photo Capture:** Captures evidence photos quietly using Camera2 API on SOS trigger.
- **🎙️ Ambient Audio Recording:** Quietly records ambient audio clips saved securely in local SQLite history.
- **🧮 Camouflage Calculator Mode:** Discreet calculator view (`9999=` secret PIN) for triggering SOS secretly.
- **📱 App Icon Disguise:** Camouflage launcher icon as a Calculator, Compass, or Clock.
- **📞 Fake Call Simulator:** Triggers a realistic fake incoming call to exit uncomfortable situations.
- **🧪 Safety Sandbox & Trial Area:** Dedicated sandbox screen to test camera, audio, whistle, and SMS features safely.
- **🔒 Debounce Protection:** 10-second debounce lock prevents accidental repeated SMS alert loops.
